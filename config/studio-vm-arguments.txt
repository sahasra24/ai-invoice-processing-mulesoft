Anypoint Studio: Run > Run Configurations > Mule Applications > (your config) > Arguments > VM arguments

Local run (defaults from config/local.yaml are used for everything else):
    -M-Denv=local

Production-like run with encrypted secrets:
    -M-Denv=prod -M-Dmule.key=<your-16-char-key>

MUnit from Studio (Run > Run Configurations > MUnit > Arguments):
    -Denv=test
